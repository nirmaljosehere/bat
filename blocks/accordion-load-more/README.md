# accordion-load-more

Custom **accordion** block. Purpose: FAQ list of expandable question/answer rows that initially shows the first 5 items and reveals the rest via a Load More button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per FAQ item; cell 1: question (summary text); cell 2: answer (rich text). Author every item; the Load More button is generated by the block when there are more than 5 items.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
