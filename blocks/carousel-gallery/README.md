# carousel-gallery

Custom **carousel** block. Purpose: Horizontally scrolling product media gallery (images and an optional video) with previous/next arrows.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1: image (optionally plus a link or plain-text URL to an .mp4 video, the image becoming the video poster); cell 2 (optional): caption text.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
