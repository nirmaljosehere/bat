# hero-foreground

Custom **hero** block. Purpose: Full-width banner with a background video or photo, a centred foreground product image and overlaid heading/intro text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image (the video poster), optionally plus a link or plain-text URL to an .mp4 background video; row 2: foreground product image followed by heading and paragraph(s).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
