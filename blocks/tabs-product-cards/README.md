# tabs-product-cards

Custom **tabs** block. Purpose: Pill tabs (e.g. Find a Flavour / More from Vuse) with a per-tab View all link; panels are horizontally scrolling carousels of bordered product cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab; cell 1: tab label; cell 2: panel content as rich text. Optional first paragraph containing only a link = the tab's View all link. Then one product card per image: the packshot image first, followed by badge/price paragraphs, H3 product name and a link to the product detail page.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
