# tabs-tile-carousel

Custom **tabs** block. Purpose: Pill tabs (e.g. Features / In The Box) whose panels are horizontally scrolling carousels of tall photo tiles with overlaid text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab; cell 1: tab label; cell 2: panel content as rich text. Each tile starts with its image, followed by its H3 title and paragraph; any heading/text before the first image becomes a text-only intro tile.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
